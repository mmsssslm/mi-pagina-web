# Equilibrio Organizacional - Sitio Web Académico

Sitio web corporativo para consultora de Psicología Industrial y Clima Laboral en Centroamérica. Desarrollado con HTML5 semántico, CSS3 estilizado con diseño responsivo y JavaScript para interactividad fluida.

---

## 🚀 Secciones del Sitio Web
- **Inicio / Hero**: Propuesta de valor, llamado a la acción y contadores de impacto (+120 empresas, -28% rotación, 92% fidelidad).
- **Nosotros**: Misión, Visión y los 4 pilares rectores (Evidencia, Confidencialidad, Ética profesional y Cercanía).
- **Servicios Especializados**: 7 tarjetas modulares que cubren clima laboral, selección, capacitación, desempeño, riesgos psicosociales, coaching y gestión del cambio.
- **Metodología**: Proceso cronológico en 4 pasos (Diagnóstico, Diseño, Intervención y Seguimiento).
- **Equipo Consultor**: Perfiles de psicólogos organizacionales con formación de posgrado y experiencia en la industria.
- **Casos de Éxito**: Métricas reales de impacto en manufactura, servicios/BPO y logística.
- **Preguntas Frecuentes**: Acordeón interactivo con respuestas sobre costos, tiempos, confidencialidad y modalidades.
- **Contacto y Formulario**: Formulario funcional con validación en tiempo real y canales directos (WhatsApp y correo).
- **Pie de Página**: Aviso académico reglamentario: *"© 2026 Equilibrio Organizacional. Empresa ficticia creada con fines académicos."*

## 🌐 Cómo activarlo gratis en GitHub Pages (para tener enlace público)
Dado que el proyecto está hecho en HTML, CSS y JS puro, puedes activar **GitHub Pages** para tener tu página publicada en internet gratis:

1. Ve a tu repositorio en GitHub: [https://github.com/mmsssslm/mi-pagina-web](https://github.com/mmsssslm/mi-pagina-web)
2. Haz clic en la pestaña **Settings** (Configuración) arriba a la derecha.
3. En el menú de la izquierda, haz clic en **Pages**.
4. En la sección **Build and deployment > Branch**:
   - Selecciona la rama **`main`**.
   - Carpeta: **`/ (root)`**.
   - Haz clic en **Save** (Guardar).
5. En unos 30 segundos, GitHub te dará un enlace público tipo:
   `https://mmsssslm.github.io/mi-pagina-web/`
